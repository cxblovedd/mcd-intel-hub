## 人格体系总览

画像 = **1 个核心人格** + **3 个副标签** + **N 个隐藏徽章**

### 核心人格（8 型，由口味主导决定）

| 口味维度 | 人格名 | Slogan |
|---|---|---|
| 甜品饮料 | 甜品判官 | 冰淇淋和麦旋风是你续命的理由 |
| 鸡腿风味 | 炸鸡教父 | 你的麦门生涯绕不开那一口酥脆鸡腿 |
| 牛肉重口 | 肉食暴君 | 双层芝士从不手软，你对碳水的爱很坦荡 |
| 深海鱼类 | 深海渔夫 | 鱼系菜单的深度用户，鳕鱼是你的老朋友 |
| 麦满分早餐 | 早餐教父 | 早八人的命是麦满分给的 |
| 小食组合 | 小食囤家 | 单点小食才是你的快乐源泉 |
| 联名收藏 | 联名猎人 | 你来麦当劳，八成不全是为了吃 |
| 酱香重口 | 酱料研究员 | 韩式辣椒黄油风味酱是你的本命 |

**判定门槛**：有效订单少于 3 笔时不给核心人格，显示「麦门新客」并提示还差几笔。

### 副标签（三个维度）

**作息节律** — 按 `createTime` 的小时分段：

| 标签 | 条件 | 解读 |
|---|---|---|
| 早餐党 | 6-10 点 | 清晨的第一口麦门，是一天的正确打开方式 |
| 午餐党 | 10-14 点 | 午间补给站，稳定输出型选手 |
| 下午茶党 | 14-17 点 | 三点半的快乐，靠一杯麦咖啡续命 |
| 晚餐党 | 17-21 点 | 下班后的快乐据点，夜里最忙的那阵 |
| 深夜党 | 21-6 点 | 深夜食堂常客，夜晚才是你的黄金时段 |

**消费足迹** — 按 `storeName` 去重与城市识别：

| 标签 | 条件 | 解读 |
|---|---|---|
| 跨城游侠 | ≥3 座城市 | 足迹遍布 N 座城市，M 家门店 |
| 门店常驻客 | ≥3 家门店 | 常驻 M 家门店，认准那几个熟悉的味道 |
| 社区守望者 | 1-2 家门店 | 你的麦门据点是 N 家门店 |

**消费习惯** — 按 `realTotalAmount > 0` 的均值分档：

| 标签 | 条件 | 解读 |
|---|---|---|
| 重度消费者 | ≥¥60 | 平均每单 ¥N，出手相当阔绰 |
| 稳健型消费者 | ≥¥30 | 平均每单 ¥N，花钱花得明白 |
| 轻量型消费者 | ≥¥10 | 平均每单 ¥N，小满足就够了 |
| 薅羊毛大师 | <¥10 | 平均每单 ¥N，靠券活着 |
| 权益型消费者 | 全部实付 0 | 订单多为积分兑换或优惠，用权益把成本压得很低 |

### 隐藏徽章（叠加，可同时解锁多个）

| 徽章 | 解锁条件 |
|---|---|
| 麦门全收集家 | 口味覆盖全部 8 类 |
| 麦门打卡狂人 | 消费跨度 ≥ 8 个月 |
| 麦金学徒 | 累计消耗积分 ≥ 5000 |

**设计说明**：隐藏徽章**不覆盖**核心人格，而是叠加展示。这样即使解锁了徽章，用户仍能看到自己真正的口味人格，信息量更大、收集感更强。

## 合规约束（重要）

海报是公开传播内容，以下为硬性红线，违反可能导致取消参赛资格：

**✅ 可以**

- 自嘲式人格名（「肉食暴君」「薅羊毛大师」指向用户自己）
- 客观陈述消费数据（订单数、金额、门店数）
- 口味偏好描述（「甜品党」「鸡腿党」）

**❌ 禁止**

- 任何评价麦当劳产品或品牌的表述
- 与其他品牌或竞品的对比
- 「热量炸弹」「放纵」「罪恶」「不健康」等词
- 任何健康建议（如「你摄入了过多热量」）
- 暗示麦当劳优于其他快餐品牌的表述

**必须保留**：免责声明「仅供娱乐，不构成健康或营养建议」。

## 数据说明

样本数据来自 `data/sample_orders.json`，已做脱敏处理（移除订单号、门店编码、账户ID），保留商品名称、时间、金额、门店名称以验证算法准确性。

实际使用时由 MCP `order-list` 实时返回，**不在仓库中存放任何真实用户订单数据**。
