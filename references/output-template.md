# 简报输出模板

技能默认输出结构。所有时间、价格、库存必须来自 MCP 实时返回，禁止推测。

---

## 默认简报模板

```markdown
## 情报速览
获取时间：{YYYY-MM-DD HH:mm}（北京时间）

### 下一个开抢窗口

> **{活动名称}**
> 开抢时刻：**{MM月DD日 HH:MM}**（还有 {X} 小时 {Y} 分钟）

后续窗口：
- {活动名称} · {MM月DD日 HH:MM} · 还有 {X} 天 {Y} 小时
- {活动名称} · {MM月DD日 HH:MM} · 还有 {X} 天 {Y} 小时

### 活动分组

**{分组名}**
- {活动名称} · {MM月DD日 HH:MM} `抢购`

**{分组名}**
- {活动名称} · {MM月DD日 HH:MM}

### 券池状态

- 可领券：{N} 张
  - {券名1}
  - {券名2}
- 已持有券：{M} 张

### 限量抢兑情报

| 商品 | 所需积分 | 开抢时间 | 限购说明 |
|---|---:|---|---|
| {商品名称} | {积分} | {MM月DD日 HH:MM} | {selling 摘要} |

### 积分抽奖情报

- 活动状态：{进行中 / 未开始 / 已结束}
- 单次消耗：{N} 积分
- 当前可用积分：{N}
- 奖品概况：{奖品列表}

---

*本简报由麦麦情报站生成，数据来自麦当劳 MCP 实时接口。活动时间、价格及库存以官方渠道实时结果为准。*
```

---

## 场景变体

### 无开抢窗口时

```markdown
### 下一个开抢窗口

> 近期无定时开抢活动，可关注积分商城的限量兑换与优惠券领取。
```

### 工具调用失败时

对应板块降级为：

```markdown
### 券池状态

> 优惠券接口未返回，本板块数据缺失。
```

**不使用任何推测数据填充。**

### 仅查询积分抽奖时

用户只想了解抽奖情况，不展示活动分组，缩短输出：

```markdown
### 积分抽奖情报

- 活动状态：进行中
- 单次消耗：24 积分
- 当前可用积分：485.7
- 奖品概况：优惠券 9 种 + 积分奖 1 种

（未执行抽奖。如需抽奖请明确告知，抽奖将消耗真实积分。）
```

## 写作要求

| 要求 | 说明 |
|---|---|
| 倒计时加粗 | 这是用户最关心的信息，视觉优先级最高 |
| 单位完整 | 积分写「积分」，价格写「元」，不省略 |
| 控制长度 | 单个板块不超过 8 条，超出则分组或折叠 |
| 无营销话术 | 结尾不添加「快去试试」「超级划算」类表达 |
| 时间标注 | 简报头部必须标注情报获取时间 |

---

## 合规约束

以下内容**不得出现在输出中**，此为活动规则明确禁止项：

- 对麦当劳产品或品牌的评价性、对比性表述（如与竞品比较）
- 贬损品牌、产品的任何表达
- 宣扬不健康饮食方式的表达（如「随便吃」「放纵」「热量炸弹」）
- 涉及营养信息时的健康建议式表达（仅客观陈述 MCP 返回的营养成分数值）
- 与麦当劳无关的内容
