## 它不分析你吃了什么，它定义你是谁

市面上的点餐助手都在算卡路里、算价格。没人告诉你：**你在这家快餐店里，是个什么样的人。**

麦门人格读完你的真实订单，从口味、作息、足迹、消费四个维度给你一个人格标签 —— 然后你会想发给同事。

```markdown
你的人格是「甜品判官」

甜品饮料 × 9 件、小食组合 × 8 件
午餐党 · 跨城游侠 · 稳健型消费者
```

> 以上来自一份跨越 8 个月、4 座城市、6 家门店的真实订单记录。

---

## 四个维度，全部有据可查

| 维度 | 从哪来 | 怎么算 |
|---|---|---|
| **口味人格** | 订单商品明细 | 展开套餐子项，按 8 类口味标签计票，取 Top2 |
| **作息节律** | 下单时间戳 | 按小时分段：早餐党 / 午餐党 / 下午茶党 / 晚餐党 / 深夜党 |
| **消费足迹** | 门店名称 | 去重后识别城市数：≥3 城跨城游侠，≥3 店门店常驻客 |
| **消费习惯** | 实付金额 | 均值分档：重度 / 稳健 / 轻量 / 权益型 |

**没有随机数。** 换成谁的数据，就得出谁的画像。

**三个副标签**

| 维度 | 可选标签 | 判定依据 |
|---|---|---|
| 作息节律 | 早餐党 / 午餐党 / 下午茶党 / 晚餐党 / 深夜党 | 下单小时分段 |
| 消费足迹 | 跨城游侠 / 门店常驻客 / 社区守望者 | 门店去重与城市识别 |
| 消费习惯 | 重度 / 稳健 / 轻量 / 薅羊毛大师 / 权益型 | 实付金额均值分档 |

**隐藏徽章 · 叠加解锁**

| 徽章 | 解锁条件 |
|---|---|
| 麦门全收集家 | 口味覆盖全部 8 类 |
| 麦门打卡狂人 | 消费跨度 ≥ 8 个月 |
| 麦金学徒 | 累计消耗积分 ≥ 5000 |

> 隐藏徽章**不覆盖**核心人格，而是叠加展示 —— 解锁徽章的同时，你依然能看到自己真正的口味人格。

## 快速开始

### 环境要求

- Python 3.8+
- 麦当劳 MCP Token（[免费申请](https://open.mcd.cn/mcp)）

### 1. 配置 MCP

```bash
git clone https://github.com/cxblovedd/mcd-intel-hub.git
cd mcd-intel-hub
```

参考 `mcp-config.example.json` 配置你的 MCP 客户端：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

### 2. 安装 Skill

把仓库放入你的 Agent Skills 目录（WorkBuddy 用户在「专家·技能·连接器」中启用即可）。

### 3. 生成你的画像

在对话框里问一句：

> 我的麦门人格是什么？

或者直接跑脚本：

```bash
# 离线演示，无需 Token
python3 scripts/persona_builder.py --demo

# 用真实订单生成
python3 scripts/persona_builder.py --orders orders.json
```

## 使用说明

| 你问 | 它做什么 |
|---|---|
| 我的麦门人格是什么？ | 四维度画像 + 数据档案 + 口味雷达 |
| 生成我的麦门画像 | 同上，可指定是否要海报版 |
| 麦当劳现在有什么活动？ | 开抢倒计时 + 限量抢兑雷达 + 券池 + 积分规划 |
| 下一个开抢是什么时候？ | 只输出时间敏感情报 |

**边界情况都处理好了**：0 笔订单输出「麦门新客」，1 笔订单也能出画像，全取消订单按 0 笔处理，全积分兑换订单标记为「权益型消费者」。**数据不足时如实说不足，不用随机数凑。**

## 另一个能力：开抢情报

麦门人格之外，同一套 MCP 底座还能帮你盯着：

- ⏰ **开抢倒计时** — 从活动文案抽出「10:45 开售」算出实时倒计时，自动剔除过期项
- 🔍 **限量抢兑雷达** — 识别积分商城里的「准时开抢 / 先到先得 / 每人限购」
- 🎫 **券池盘点** — 可领券与已持有券一目了然
- 💎 **积分规划** — 每积分换算价值对照
- 👨‍👩‍👧 **亲子活动** — 派对 / 品鉴会 / 体验营预约全链路

详见 `SKILL.md` 与 `MCP_INTEGRATION.md`。

## 设计原则

**不做健康建议。** 人格是趣味标签，不是营养指导。输出末尾固定带免责声明，不做任何「你摄入了过多热量」式提醒。

**不评价品牌。** 人格标签指向用户自己，不评价麦当劳的产品，也不与任何品牌对比。

**不用随机数。** 每个标签都能追溯到具体订单记录。数据不足就说不足。

**原始数据不留存。** 仓库内只有脱敏样本，真实订单数据仅在内存中处理。
