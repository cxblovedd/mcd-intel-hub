# assets

分享素材目录。

| 文件 | 用途 |
|---|---|
| `persona-poster.html` | **人格海报生成器**。单文件，浏览器打开即可预览，输出 1080×1440 PNG，支持下载与复制到剪贴板。 |
| `preview.html` | 早期情报简报宣传图，保留供参考。 |

## 海报结构（v4 体系）

从上到下共七个区块：

1. **品牌栏** — `MC WHOAMI · 麦门人格` + 右侧置信度标签
2. **人格名** — 最大视觉焦点，下面跟一句 slogan
3. **隐藏副人格** — 若得分接近则并列展示（可整块删除）
4. **口味权重** — 条形图 + 加权得分（S= 0.5×件数 + 0.3×订单 + 0.2×复购）
5. **你的麦门属性** — 作息 / 足迹 / 消费三标签横排
6. **徽章收集** — 已解锁为实底，未解锁为虚线剪影
7. **数据档案** — 订单数 / 月份 / 城市 / 门店 + 引导语

## 换成你自己的画像

1. 用 `scripts/persona_builder.py` 生成你的画像输出
2. 打开 `persona-poster.html`，按下表替换：

| 要改的 | 位置 | 说明 |
|---|---|---|
| 置信度 | `.conf` | 正式画像 / 初步画像 / 探索中 |
| 人格名 | `.persona` | |
| Slogan | `.slogan` | |
| 副人格 | `.sub` | 无副人格则删除整块 |
| 口味权重 | `.radar-row` | 改标签、`width` 百分比、`.radar-num` 得分 |
| 三标签 | `.trait` | 标签名与维度名 |
| 徽章 | `.badge` | 已解锁用 `.badge`，未解锁用 `.badge badge-locked` |
| 数据档案 | `.stat` | 四个数字与标签 |

3. 点击「下载图片」得到 1080×1440 PNG
